# SeasonCat v0.9.5-rs.3

SeasonCat 是基于 FlClash v0.9.5-rs.1 的 Android 代理客户端，界面为 Rust + Slint，内核为 Concord。本版继续对照 FlClash rs 移植界面细节，安装包改由 Gradle 直接构建，不再包含 Flutter。

## 新功能
- 代理组展开、收起改为弹簧动画，动画中途点按会从当前位置反向，折叠箭头随之旋转。
- 配置编辑器、运行时配置、规则集预览、代理快速编辑先打开再加载，加载中显示转圈，读取失败时在页面内说明原因；字体页与出口弹层同样处理。
- 请求页各行与连接、DNS、HTTP 详情改为一行文字后跟标签，窄屏时文字先让位。
- MITM 主机名页按已启用的模块分区列出主机，标出已排除的主机和内核拒绝的原因，搜索可查到模块分区。
- 模块路由规则只标出内核未采用的条目并给出原因，规则行按此计数无效条目。
- 宽屏侧栏改为 FlClash rs 样式：840 以上可固定展开并记住选择，600–840 展开为浮层；宽屏下请求详情以侧边弹层打开。
- 设置行高度随字号变化，最小 44。

## 问题修复
- 根页按返回键：开启“退出时最小化”（默认）时退到后台，关闭时退出应用，与 FlClash 一致。

## 其他
- 移除 Flutter / Dart 代码与工具链，安装包由 Gradle 构建；可直接覆盖安装 v0.9.5-rs.2。

## 已知限制
- 暂仅提供 arm64-v8a 安装包。
- 界面仅有中文，语言设置只保存选项。

## 校验
- 安装包 `FlClash-0.9.5-rs.3-android-arm64.apk` 的 SHA-256 见同一发布中的 `FlClash-0.9.5-rs.3-SHA256SUMS`，应用内更新下载后按该文件校验。
