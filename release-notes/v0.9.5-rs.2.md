# SeasonCat v0.9.5-rs.2

SeasonCat 是基于 FlClash v0.9.5-rs.1 的 Android 代理客户端，界面改用 Rust + Slint 重写，内核为 Concord。本版是 Slint 界面的首个正式版。

## 新功能
- 全新 Slint 界面，页面与功能对齐 FlClash：仪表盘、代理、配置、工具、请求；手机底栏（悬浮/固定）与平板侧栏、多列布局。
- 自定义配置：策略组、成员与图标选择、规则、外部资源、拨号代理、DNS/NTP/域名嗅探覆写、导入 YAML 与应用本地代理。
- 配置扩展：附加规则（拖动排序）、出口、扩展脚本（QuickJS）。
- MITM：HTTPS 解密、证书安装与信任检查、模块（附件、网络设置、自动更新）、主机名、抓包。
- 请求页：连接 / HTTP / DNS 三个记录、条件筛选、带计数的状态菜单、跟随最新记录与时间滚动条；开启 HTTP 抓包时“请求”进入手机底栏。
- 二维码导入（应用内相机扫描）、TV 从手机发送链接、install-config 链接、快捷方式与快捷设置磁贴。
- 应用内检查与下载更新（校验 SHA-256 后安装）。

## 问题修复
- 规则类型按配置写法显示（DOMAIN-SUFFIX 而非 DOMAIN_SUFFIX），类型选择与搜索同样。
- 仪表盘“实时连接”打开活动连接；状态为空时显示对应文案（如“暂无活动连接”）。
- 切换配置后通知标题随之更新。

## 性能优化
- 仅在 MITM 开启时轮询内存；通知与流量统计只接收变化的流量样本，后台更省电。
- 内核更新到 Concord main（78e16c1）：网络切换后重置 DNS 上游连接、空规则集文件正确解析、WireGuard 拆除顺序、AnyTLS / Hysteria 传输与调度修复。

## 已知限制
- 暂仅提供 arm64-v8a 安装包。
- 代理组展开动画、页面加载转圈、MITM 主机名页的模块分组尚未移植。

## 校验
- 安装包 `FlClash-0.9.5-rs.2-android-arm64.apk` 的 SHA-256 见同一发布中的 `FlClash-0.9.5-rs.2-SHA256SUMS`，应用内更新下载后按该文件校验。
