# SeasonCat v0.9.5-rs.4

SeasonCat 是基于 FlClash v0.9.5-rs.1 的 Android 代理客户端，界面为 Rust + Slint，内核为 Concord。本版继续对照 FlClash rs 补齐界面功能，并修复几处卡顿与配置竞争问题。

## 新功能
- 代理页与仪表盘策略组卡片显示策略组图标，按图标样式（色块、纯图标、隐藏）绘制，无图标时显示首字。
- 配置编辑器支持查找替换、撤销重做、字号、换行与配置键值补全；离开未保存的配置编辑前会询问。
- HTTP 请求详情按类型显示正文，支持预览与十六进制页，并提供 FlClash rs 的请求菜单。
- 配置详情的外部资源可更新、上传、预览、编辑文本并显示用量；扩展脚本显示脚本名。
- MITM 模块显示远程文件状态并可重新下载；高级页 MITM 行与 FlClash rs 一致。
- IP 质量弹层显示标记、ASN、来源并可重新查询；内存弹层显示内核占用。
- 未使用配置时出站卡说明全部直连；批量导入显示添加与跳过数量；出口弹层显示脚本失败原因。
- 启动保护：连续崩溃后显示启动失败页，只统计真正的崩溃，系统或用户停止进程不计入。

## 问题修复
- 首次添加自定义配置不再卡住界面。
- 多次快速切换配置或修改设置时，按最后一次选择生效，不会被旧配置覆盖。
- 设置在后台写入，修改时界面更流畅。
- 停止运行后流量清零；长按菜单在按压处弹出，不再盖住所按的行；添加菜单锚定在按钮处。
- 访问控制栏与请求列表不再被底栏遮挡。

## 其他
- 应用更新与发布文件统一改名为 `SeasonCat-`；移除语言选择，界面固定中文；清理无用代码。

## 已知限制
- 暂仅提供 arm64-v8a 安装包。
- v0.9.5-rs.3 的应用内更新只识别 `FlClash-` 文件，请从发布页手动安装本版，可直接覆盖安装并保留数据。

## 校验
- 安装包 `SeasonCat-0.9.5-rs.4-android-arm64.apk` 的 SHA-256 见同一发布中的 `SeasonCat-0.9.5-rs.4-SHA256SUMS`。
