# SeasonCat v0.9.5-rs.5

SeasonCat 是基于 FlClash v0.9.5-rs.1 的 Android 代理客户端，界面为 Rust + Slint，内核为 Concord。本版新增崩溃日志页，并让策略组图标支持 SVG 与 JPEG。

## 新功能
- 工具 → 其他 新增「崩溃日志」：显示上次进程退出的原因（崩溃、原生崩溃、内存不足、被系统或用户停止、ANR 等）、时间与说明（Android 11 及以上），以及应用记录的崩溃日志，可复制与清除。
- 策略组与网络图标支持 SVG：http 地址与 `data:image/svg+xml`（base64、百分号编码或原文）均可显示，按内容识别格式。
- 策略组与网络图标支持 JPEG：http 地址与 `data:image/jpeg` 均可显示。

## 已知限制
- 暂仅提供 arm64-v8a 安装包。
- SVG 中按文件路径引用的图片不会读取，只绘制以 data url 内嵌的图片。

## 校验
- 安装包 `SeasonCat-0.9.5-rs.5-android-arm64.apk` 的 SHA-256 见同一发布中的 `SeasonCat-0.9.5-rs.5-SHA256SUMS`。
